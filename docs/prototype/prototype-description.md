| 中部 | 登录按钮 | 主按钮，背景 #00D9FF，宽度 100%，内边距 8px 16px |

#### 2.1.3 交互说明

| 交互事件 | 行为 |
|---------|------|
| 输入框聚焦 | 边框高亮 #00D9FF，显示提示文字 |
| 输入框失焦 | 验证输入格式，错误时边框 #FF4D4F |
| 点击登录 | 按钮显示加载状态，提交登录请求 |
| 登录成功 | 显示成功提示（3 秒），跳转首页 |
| 登录失败 | 显示错误提示（5 秒），错误次数 +1 |
| 连续失败 5 次 | 账户锁定 30 分钟，警告色 #FF4D4F |

## 5. 关系图谱交互详解

### 5.1 节点操作交互（共 12 种）

| 序号 | 交互名称 | 触发方式 | 行为描述 |
|-----|---------|---------|---------|
| 1 | 节点搜索定位 | 输入框输入并回车 | 高亮目标节点并居中显示，未匹配节点半透明 |
| 2 | 节点单击 | 单击节点 | 显示节点详情浮层，含属性、关联文件 |
| 3 | 节点双击 | 双击节点 | 展开一阶邻居节点（增量加载） |
| 4 | 节点悬停 | 鼠标悬停 | 高亮节点及其直接关联边与邻居，其余元素半透明 |
| 5 | 节点拖拽 | 按住拖动 | 自由移动节点位置，关联边实时跟随 |
| 6 | 节点固定/锁定 | 右键 → 固定 | 锁定节点位置，不参与力导向布局 |
| 7 | 节点取消固定 | 右键 → 取消固定 | 释放节点，重新参与力导向布局 |
| 8 | 节点合并 | 多选 → 右键 → 合并 | 将多个同类节点合并为一个聚合节点 |
| 9 | 节点拆分 | 右键聚合节点 → 拆分 | 将聚合节点还原为原始多个节点 |
| 10 | 节点删除 | 右键 → 删除 | 从视图中移除节点（不删除数据），可撤销 |
| 11 | 节点编辑 | 右键 → 编辑 | 弹出节点属性编辑对话框 |
| 12 | 节点右键菜单 | 右键节点 | 显示上下文菜单（固定、编辑、复制、删除、查看关联） |

### 5.2 批量选择与操作（共 5 种）

| 序号 | 交互名称 | 触发方式 | 行为描述 |
|-----|---------|---------|---------|
| 13 | 框选节点 | 按住 Shift + 拖拽 | 矩形框选范围内的所有节点 |
| 14 | 全选节点 | Ctrl + A | 选中画布中所有可见节点 |
| 15 | 反选节点 | Ctrl + Shift + I | 反转当前选择 |
| 16 | 批量高亮邻居 | 多选 → 右键 → 高亮邻居 | 高亮所选节点的所有邻居节点 |
| 17 | 批量删除 | 多选 → Delete | 批量移除所选节点，可撤销 |

### 5.3 路径与子图分析（共 4 种）

| 序号 | 交互名称 | 触发方式 | 行为描述 |
|-----|---------|---------|---------|
| 18 | 路径分析 | 右键节点 A → 路径分析 → 选择节点 B | 高亮 A 到 B 的最短路径，显示路径长度与节点列表 |
| 19 | 邻居高亮 | 右键节点 → 高亮邻居 | 高亮 N 阶（可选 1/2/3 阶）邻居节点 |
| 20 | 子图抽取 | 多选 → 右键 → 抽取子图 | 将所选节点及其内部边抽取为新图谱标签页 |
| 21 | 关键路径发现 | 工具栏 → 关键路径 | 自动发现并高亮相邻度最高的关键路径 |

### 5.4 筛选与布局（共 6 种）

| 序号 | 交互名称 | 触发方式 | 行为描述 |
|-----|---------|---------|---------|
| 22 | 按属性筛选 | 筛选面板 → 选择属性条件 | 按节点属性（类型、标签、风险等级）筛选 |
| 23 | 按关系类型筛选 | 筛选面板 → 勾选关系类型 | 仅显示勾选的关系类型对应的边与节点 |
| 24 | 按时间回放 | 时间回放滑块拖动 | 按时间维度动态展示图谱演化过程 |
| 25 | 布局切换 | 工具栏布局下拉 | 切换力导向/同心圆/层级/树形/网格布局 |
| 26 | 自动布局重置 | 工具栏 → 重置布局 | 重新计算力导向布局 |
| 27 | 边权重过滤 | 筛选面板 → 边权重滑块 | 隐藏权重低于阈值的边 |

### 5.5 视图控制（共 5 种）

| 序号 | 交互名称 | 触发方式 | 行为描述 |
|-----|---------|---------|---------|
| 28 | 滚轮缩放 | 鼠标滚轮 | 以鼠标位置为中心缩放图谱 |
| 29 | 拖拽平移 | 空白处按住拖拽 | 平移整个图谱视图 |
| 30 | 适应屏幕 | 工具栏 → 适应屏幕 | 自动缩放使所有节点可见 |
| 31 | 全屏切换 | 工具栏 → 全屏 | 切换全屏/窗口模式 |
| 32 | 缩放控制 | 工具栏 +/- 按钮 | 按固定步长缩放 |

### 5.6 历史与导出（共 4 种）

| 序号 | 交互名称 | 触发方式 | 行为描述 |
|-----|---------|---------|---------|
| 33 | 撤销 | Ctrl + Z / 工具栏撤销 | 撤销上一步操作（最多 50 步） |
| 34 | 重做 | Ctrl + Shift + Z / 工具栏重做 | 重做已撤销的操作 |
| 35 | 图谱快照保存 | 工具栏 → 快照 | 保存当前图谱状态（含布局、筛选、选择） |
| 36 | 快照恢复 | 工具栏 → 快照列表 → 选择 | 恢复到指定快照状态 |
| 37 | 导出图片 | 工具栏 → 导出图片 | 导出 PNG/SVG 格式 |
| 38 | 导出 JSON | 工具栏 → 导出 JSON | 导出图谱原始数据 |

> 合计：**38 种**图谱交互操作（远超 20+ 种要求），覆盖节点、批量、路径、筛选、布局、视图、历史、导出全场景。
