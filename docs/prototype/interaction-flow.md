### 1.1 用户认证流程

#### 1.1.1 登录流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                              用户登录流程                                    │
└─────────────────────────────────────────────────────────────────────────────┘

开始
  │
  ▼
┌─────────────────┐
│  访问登录页面    │   背景 #0D1117，卡片 #161B22
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  选择登录方式    │ ◄──────────────────────────────────┐
│  (密码/LDAP/SSO) │                                    │
└────────┬────────┘                                    │
         │                                             │
         ▼                                             │
┌─────────────────┐                                    │
│  输入认证信息    │                                    │
└────────┬────────┘                                    │
         │                                             │
         ▼                                             │
┌─────────────────┐                                    │
│  点击登录按钮    │   主色 #00D9FF，内边距 8px 16px     │
└────────┬────────┘                                    │
         │                                             │
         ▼                                             │
┌─────────────────┐    否    ┌─────────────────┐       │
│  验证通过？      ├────────►│  显示错误提示    │       │
└────────┬────────┘          │  (错误次数+1)   │───────┘
         │ 是                 │  错误色 #FF4D4F │
         ▼                   │  显示 5 秒      │
┌─────────────────┐          └─────────────────┘
│  锁定账户？      │    是    ┌─────────────────┐
│  (失败>=5次)     ├────────►│  显示锁定提示    │
└────────┬────────┘          │  (等待30分钟)   │
         │ 否                 └─────────────────┘
         ▼
┌─────────────────┐
│  创建会话        │
│  记录登录日志    │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  跳转首页        │   成功提示显示 3 秒
└────────┬────────┘
         │
         ▼
结束
```

**流程说明：**

| 步骤 | 操作 | 系统响应 | 异常处理 |
|-----|------|---------|---------|
| 1 | 用户访问登录页面 | 显示登录表单 | - |
| 2 | 选择登录方式 | 切换对应表单 | - |
| 3 | 输入认证信息 | 实时验证格式 | 格式错误即时提示 |
| 4 | 点击登录 | 提交认证请求 | 网络错误提示重试 |
| 5 | 验证通过 | 创建会话，跳转首页，成功提示 3 秒 | 验证失败显示错误，错误提示 5 秒 |
| 6 | 连续失败 5 次 | 锁定账户 30 分钟 | 警告色提示，4 秒自动消失 |

**关键交互点：**

| 交互阶段 | 用户操作 | 系统反馈 | 进度显示 |
|---------|---------|---------|---------|
| 文件选择 | 拖拽或点击选择 | 高亮上传区域 | - |
| 校验阶段 | 等待 | 显示校验进度 | 0-10% |
| 哈希计算 | 等待 | 显示计算进度 | 10-20% |
| 上传阶段 | 可暂停/取消 | 实时进度条 | 20-90% |
| 服务端处理 | 等待 | 显示处理状态 | 90-100% |
| 完成 | 查看/跳转 | 成功提示 3 秒 | 100% |

**批量上传状态说明（深色主题状态色）：**

| 状态 | 图标 | 颜色 | 说明 |

### 6.3 快捷键使用说明

- **快捷键冲突处理**：当浏览器默认快捷键与本平台冲突时，本平台快捷键优先（除 Ctrl+N/Ctrl+T 等系统级快捷键）
- **输入框内禁用**：在输入框聚焦时，除 Ctrl+A/Ctrl+C/Ctrl+V/Ctrl+X/Esc 外，其他快捷键不生效
- **快捷键提示**：鼠标悬停按钮时，工具提示中显示对应快捷键
- **快捷键帮助**：按 `Ctrl + /` 或 `?` 可呼出快捷键速查表
- **可配置**：用户可在设置中自定义快捷键映射
