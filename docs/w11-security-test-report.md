## 一、测试概述

### 1.1 测试目标

- 验证平台符合 OWASP Top 10 (2021) 安全风险防控要求。
- 验证国密算法 SM2/SM3/SM4 的实现正确性、标准向量一致性。
- 验证 MFA 多因素认证的安全性，包括 TOTP、备用码、暴力破解防护。
- 验证 JWT/Token 黑名单/会话管理的安全性。
- 验证敏感字段加密、传输加密、存储加密合规性。
- 验证第三方依赖漏洞与代码审计结果。
