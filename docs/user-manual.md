## 一、平台简介

### 1.1 平台定位

红方文件分析管理平台是面向网络安全红队（攻击模拟团队）的文件汇聚、解析、检索、分析、画像一体化作战平台。平台支持多源文件汇聚（本地/爬虫/导入），自动解析文件结构，提供混合检索（全文+元数据+向量），自动提取 IOC 与实体，构建目标画像与关系图谱。

### 1.2 核心能力

| 能力 | 说明 |
|---|---|
| 文件汇聚 | 单文件/分片/秒传/批量上传，支持 200+ 文件类型 |
| 文件解析 | 文档/图片/二进制结构化解析，自动抽取文本/图片/链接 |
| 混合检索 | 全文检索 + 元数据过滤 + 语义向量检索（RRF 融合） |
| IOC 提取 | 自动识别 IP/域名/Hash/URL，关联威胁情报 |
| 实体识别 | 抽取人名/组织/邮箱/电话等实体 |
| 沙箱分析 | Windows/Linux 沙箱动态分析，行为捕获 |
| 目标画像 | 目标管理 + 画像生成 + 关系图谱 |
| 任务编排 | 多步骤任务编排，状态机管理，时间线追踪 |
| 多通道通知 | 站内信/飞书/邮件/SMS 通知 |
| 报告导出 | PDF/Word/HTML 报告，模板化管理 |
| 国密合规 | SM2/SM3/SM4 全栈国密算法 |
| 团队空间 | 按团队空间隔离数据，RBAC 权限控制 |

### 1.3 用户角色

| 角色 | 角色代码 | 主要权限 | 典型用户 |
|---|---|---|---|
| 系统管理员 | ADMIN | 全部权限 | 平台运维负责人 |
| 红方管理员 | RED_ADMIN | 团队空间管理、用户管理、全部业务操作 | 红队队长 |
| 红方分析师 | ANALYST | 文件上传/检索/分析/画像 | 红队分析师 |
| 红方操作员 | OPERATOR | 文件上传/检索/任务执行 | 红队成员 |
| 审计员 | AUDITOR | 只读 + 审计日志查看 | 安全审计员 |

### 1.4 浏览器要求

| 浏览器 | 最低版本 | 推荐版本 |
|---|---|---|
| Chrome | 100+ | 最新版 |
| Edge | 100+ | 最新版 |
| Firefox | 100+ | 最新版 |
| Safari | 15+ | 最新版 |

> 不支持 IE 浏览器。推荐使用 Chrome 最新版以获得最佳体验。

## 三、登录与认证

### 3.1 登录

**访问路径**：浏览器输入 `https://redteam.example.com`

**操作步骤**：

1. 在登录页面输入用户名、密码
2. 输入图形验证码
3. 点击「登录」按钮

> **MFA 用户**：若已启用 MFA，首次登录后会要求输入 MFA 验证码，请打开 Google Authenticator / 飞书/ 企业微信等 TOTP 应用，输入 6 位验证码。

### 3.2 启用 MFA（推荐）

**路径**：登录后 -> 右上角头像 -> 「账户设置」-> 「安全设置」-> 「MFA」

**操作步骤**：

1. 点击「启用 MFA」
2. 使用 TOTP 应用（如 Google Authenticator）扫描二维码
3. 输入 TOTP 应用显示的 6 位验证码
4. **保存备用码**到安全位置（用于丢失设备时恢复）
5. 点击「确认启用」

> ⚠️ **重要**：备用码务必保存到安全位置，丢失设备时只能用备用码登录。

### 3.3 忘记密码

1. 在登录页点击「忘记密码」
2. 输入注册邮箱
3. 查收重置邮件（邮件有效期 30 分钟）
4. 点击邮件中的链接，设置新密码

### 3.4 修改密码

**路径**：右上角头像 -> 「账户设置」-> 「安全设置」-> 「修改密码」

**密码要求**：

- 长度 8-32 位
- 必须包含大小写字母、数字、特殊字符中的 3 种
- 90 天强制更换
- 不能与最近 5 次密码相同

### 3.5 退出登录

**路径**：右上角头像 -> 「退出登录」

> 退出后 Token 立即失效，需重新登录。

## 五、文件管理

### 5.1 文件上传

**路径**：侧边栏「文件管理」->「我的上传」-> 点击「上传」按钮

#### 5.1.1 单文件上传

1. 点击「上传」按钮或拖拽文件到上传区域
2. 选择文件（单文件 ≤ 100MB）
3. 设置元数据（可选）：
   - 标签：为文件打标签，便于后续检索
   - 是否敏感：敏感文件加密存储
   - 关联目标：关联到已有目标
4. 点击「开始上传」
5. 等待上传完成

#### 5.1.2 大文件分片上传（≥ 100MB）

1. 选择大文件（最大 5GB）
2. 系统自动分片（默认 5MB/片）
3. 显示分片上传进度
4. 上传完成后自动合并
5. 支持断点续传：上传中断后重新选择同一文件，自动续传

#### 5.1.3 秒传

- 上传前系统自动计算文件 MD5/SHA256
- 若数据库已存在相同哈希，**秒传命中**，立即返回文件 ID
- 适用场景：团队内多人上传同一文件

#### 5.1.4 上传限制

| 限制项 | 阈值 |
|---|---|
| 单文件大小 | ≤ 5GB |
| 团队空间文件数 | 100 万（可申请扩容） |
| 团队空间存储 | 1TB（可申请扩容） |
| 文件类型白名单 | 见 5.1.5 |

#### 5.1.5 支持的文件类型

| 类型 | 扩展名 |
|---|---|
| 文档 | pdf, doc, docx, xls, xlsx, ppt, pptx, txt, rtf, md |
| 邮件 | eml, msg |
| 网页 | html, htm |
| 图片 | jpg, jpeg, png, gif, bmp, tiff |
| 压缩包 | zip, rar, 7z, tar, gz |
| 可执行 | exe, dll, sys, so, dylib |
| 脚本 | js, vbs, ps1, py, sh, bat |
| 二进制 | bin, dat |
| 日志 | log, json, xml, yaml, yml |
| 其他 | iso, vmdk, mem, dump |

**功能**：

| 文件类型 | 图标 + 扩展名 |

| 解析状态 | 未解析/解析中/已解析/解析失败 |
| 分析状态 | 未分析/分析中/已分析/分析失败 |
| 风险等级 | 低/中/高/严重（颜色标识） |
| 标签 | 文件标签 |

### 5.3 文件详情

**路径**：文件列表点击文件名

**页面内容**：

| 标签页 | 说明 |
|---|---|
| 基本信息 | 文件名/大小/类型/哈希/上传者/时间 |
| 元数据 | EXIF/作者/创建时间/修改时间 |
| 解析内容 | 解析后的文本、图片、链接 |

| 实体 | 提取的人名/组织/邮箱 |

| 操作日志 | 文件相关操作日志 |

### 5.4 文件下载

1. 文件列表 -> 操作列 -> 点击「下载」
2. 或文件详情页 -> 「下载」按钮

**批量下载**：

1. 文件列表 -> 勾选多个文件
2. 点击「批量下载」
3. 系统打包为 ZIP 自动下载

### 5.5 文件分享

1. 文件详情页 -> 「分享」按钮
2. 设置：
   - 有效期：1h / 24h / 7d / 30d
   - 访问密码：可设置
   - 最大下载次数：可设置
3. 点击「生成链接」
4. 复制链接发送给他人

> ⚠️ 分享链接公开访问，请妥善保管。敏感文件请设置访问密码。

### 5.6 文件版本

1. 文件详情页 -> 「版本历史」标签页
2. 查看历史版本列表
3. 可下载历史版本
4. 可回滚到指定版本

### 5.7 文件删除与恢复

**删除**：

- 文件列表 -> 操作列 -> 「删除」
- 删除后进入「回收站」，保留 30 天

**恢复**：

1. 侧边栏「文件管理」->「回收站」
2. 选择文件 -> 「恢复」

**彻底删除**：

- 回收站 -> 「彻底删除」（不可恢复）
- 30 天后自动彻底删除

## 六、文件检索

### 6.1 检索入口

**路径**：侧边栏「文件检索」或按 `Ctrl+K` 快捷键

### 6.2 检索模式

| 模式 | 说明 | 适用场景 |
|---|---|---|
| 全文检索（FULLTEXT） | 基于文件内容的倒排索引 | 关键词匹配 |
| 元数据过滤（METADATA） | 文件名/类型/时间等结构化字段 | 精确过滤 |
| 语义检索（VECTOR） | 基于语义向量的相似度匹配 | 模糊描述/相似文件 |

> 默认开启「全文 + 元数据」混合模式。勾选「语义检索」后启用三模混合检索。

### 6.3 检索语法

#### 6.3.1 全文检索

```
钓鱼邮件                    # 检索包含"钓鱼邮件"的文件
"APT28 组织"               # 精确短语匹配
钓鱼 OR 邮件               # 任一关键词
钓鱼 AND 邮件              # 同时包含
钓鱼 NOT 邮件              # 包含"钓鱼"但不含"邮件"
勒索*                      # 通配符（前缀）
/payload.exe               # 路径包含
```

#### 6.3.2 元数据过滤

在检索框下方点击「高级筛选」：

| 筛选项 | 说明 |
|---|---|
| 文件类型 | 多选，支持扩展名 |
| 上传时间 | 时间范围 |
| 文件大小 | 范围 |
| 团队空间 | 多选 |
| 标签 | 多选 |
| 上传者 | 多选 |
| 风险等级 | 多选 |

### 6.4 检索结果

| 字段 | 说明 |
|---|---|
| 文件名 | 高亮匹配关键词 |
| 摘要 | 命中上下文片段 |
| 评分 | 相关度评分（0-1） |
| 文件类型 | 图标 + 扩展名 |
| 上传时间 | YYYY-MM-DD HH:mm |
| 团队空间 | 所属团队空间 |

**操作**：

- 点击文件名进入详情
- 点击「查看相似」启动语义检索
- 点击「下载」直接下载

### 6.5 搜索建议

输入关键词时自动联想：

- 输入前缀 → 显示补全建议
- 显示历史搜索（个人）
- 显示热门搜索（团队）

### 6.6 搜索历史

**路径**：文件检索页 -> 「历史」标签页

- 查看个人搜索历史
- 可重新执行搜索
- 可删除单条/清空全部

## 七、文件分析

### 7.1 触发分析

**方式一**：文件详情页 -> 「分析」按钮

**方式二**：文件列表 -> 操作列 -> 「分析」

**方式三**：批量分析 -> 勾选多个文件 -> 「批量分析」

### 7.2 分析类型

| 分析器 | 说明 | 耗时 |
|---|---|---|
| IOC 提取 | 自动识别 IP/域名/Hash/URL | < 30s |
| 实体识别 | 抽取人名/组织/邮箱/电话 | < 30s |
| 沙箱分析 | 动态运行，捕获行为 | 1-5 min |
| 威胁情报 | 关联外部威胁情报源 | 30-60s |

### 7.3 分析结果

#### 7.3.1 综合风险评级

| 级别 | 颜色 | 评分 | 含义 |
|---|---|---|---|
| 严重 | 红色 | 90-100 | 确认恶意，立即处置 |
| 高 | 橙色 | 70-89 | 高度可疑，建议隔离 |
| 中 | 黄色 | 40-69 | 部分可疑，需进一步分析 |
| 低 | 蓝色 | 0-39 | 暂未发现风险 |

#### 7.3.2 IOC 列表

| 字段 | 说明 |
|---|---|
| 类型 | IP / 域名 / Hash / URL |
| 值 | IOC 内容 |
| 是否恶意 | 是/否（基于威胁情报） |
| 威胁情报源 | AlienVault / VirusTotal / 自有情报 |
| 置信度 | 0-1 |
| 标签 | 威胁标签（如 ransomware, c2） |
| 关联文件 | 包含此 IOC 的其他文件 |

#### 7.3.3 沙箱报告

| 内容 | 说明 |
|---|---|
| 行为列表 | 文件/注册表/网络/进程操作 |
| 进程树 | 进程父子关系 |
| 网络连接 | 请求的 IP/域名/端口 |
| 文件操作 | 创建/修改/删除的文件 |
| 注册表操作 | 修改的注册表项 |
| 截图 | 沙箱运行截图 |

### 7.4 IOC 全局查询

**路径**：侧边栏「分析中心」->「IOC 管理」

- 查询全平台所有 IOC
- 按 IP/域名/Hash/URL 类型筛选
- 按"是否恶意"筛选
- 查看 IOC 关联的所有文件

### 7.5 分析规则

**路径**：侧边栏「分析中心」->「分析规则」

- 查看内置规则
- 创建自定义 YARA / Sigma 规则
- 启用/禁用规则
- 测试规则

## 八、目标画像

### 8.1 目标管理

**路径**：侧边栏「目标画像」->「目标列表」

#### 8.1.1 创建目标

1. 点击「新建目标」
2. 填写：
   - 目标名称：如「APT28 组织」
   - 目标类型：人物 / 组织 / 域名 / IP
   - 描述：目标背景
   - 标签：如 APT、俄罗斯
   - 关联文件：可选已有文件
3. 点击「保存」

#### 8.1.2 目标列表

- 按类型筛选
- 关键词搜索
- 查看目标统计：文件数、IOC 数、实体数

### 8.2 生成画像

1. 进入目标详情
2. 点击「生成画像」
3. 选择生成选项：
   - 是否包含文件分析
   - 是否包含 IOC
   - 是否包含实体
4. 点击「开始生成」
5. 等待生成完成（通常 1-3 分钟）

### 8.3 画像内容

| 模块 | 说明 |
|---|---|
| 摘要 | AI 生成的目标概述 |
| 基本属性 | 国家/活跃时间/目标行业/战术/恶意软件 |
| 统计 | 文件数/IOC 数/实体数/首次出现/最近出现 |
| 文件列表 | 关联的所有文件 |
| IOC 列表 | 关联的所有 IOC |
| 实体列表 | 关联的所有实体 |
| 时间线 | 目标活动时间线 |

### 8.4 关系图谱

## 十三、定时报告（V2.5 新增）

> V2.5 迭代新增「定时报告」功能，支持按 Cron 表达式自动生成报告并通过邮件推送给指定收件人。适用于周期性汇报（周报、月报、季报）与固定监控（每日威胁情报简报、每周目标分析）等场景。

### 13.1 什么是定时报告

定时报告是平台在 V2.5 迭代新增的自动化能力，可以让用户配置一条「调度规则」，平台到点自动生成指定类型的报告并通过邮件发送给指定收件人，无需人工触发。

**典型场景**：

| 场景 | 频率 | 报告类型 | 说明 |
|---|---|---|---|
| APT 组织周报 | 每周一 09:00 | 目标分析报告 | 自动汇总一周新增文件/IOC，发给红方队长与分析员 |
| IOC 简报 | 每日 08:00 | IOC 报告 | 自动汇总前一日新增 IOC，发给分析员 |
| 月度威胁总结 | 每月 1 日 09:00 | 事件报告 | 自动生成上月威胁情报汇总，发给安全主管 |
| 季度安全简报 | 每季度初 | 综合报告 | 自动生成季度安全态势，发给 CTO |

**核心特性**：

- ✅ 支持 Cron 表达式自定义频率（Quartz 风格，6/7 位）
- ✅ 支持多收件人（最多 50 个邮箱）
- ✅ 支持 PDF / Word / HTML 三种格式
- ✅ 支持启停 / 删除 / 查看历史
- ✅ 报告生成失败自动重试，邮件发送失败自动告警
- ✅ 历史记录保留 30 天，可随时回溯下载

**入口**：侧边栏「后台管理」->「报告中心」->「定时报告」Tab（V2.5 新增 Tab）

> ⚠️ **权限要求**：定时报告功能仅对 `ADMIN` / `RED_ADMIN` / `ANALYST` 角色开放，`OPERATOR` / `AUDITOR` 角色仅可查看，不能创建/修改。


### 13.3 Cron 表达式说明

平台采用 Quartz 风格的 Cron 表达式（6 或 7 位），格式如下：

```
┌──────── 秒（0-59）
│ ┌────── 分（0-59）
│ │ ┌──── 时（0-23）
│ │ │ ┌──── 日（1-31）
│ │ │ │ ┌──── 月（1-12 或 JAN-DEC）
│ │ │ │ │ ┌──── 周（1-7 或 SUN-SAT）
│ │ │ │ │ │ ┌── 年（可选，留空）
│ │ │ │ │ │ │
* * * * * * *
```

#### 13.3.1 常用 Cron 表达式速查

| 表达式 | 含义 |
|---|---|
| `0 0 8 * * ?` | 每日 08:00 |
| `0 0 9 ? * MON` | 每周一 09:00 |
| `0 0 9 ? * MON,FRI` | 每周一、五 09:00 |
| `0 0 9 1 * ?` | 每月 1 日 09:00 |
| `0 0 9 1 1,4,7,10 ?` | 每季度初 09:00 |
| `0 0 0 1 1 ?` | 每年 1 月 1 日 00:00 |
| `0 0 * * * ?` | 每小时整点 |
| `0 */6 * * * ?` | 每 6 小时 |
| `0 0 9 ? * MON-FRI` | 工作日 09:00 |
| `0 30 9 ? * MON` | 每周一 09:30 |
| `0 0 23 L * ?` | 每月最后一天 23:00（L=Last） |

#### 13.3.2 Cron 字符说明

| 字符 | 含义 | 示例 |
|---|---|---|
| `*` | 任意值 | `* * * * * ?` 每秒 |
| `,` | 枚举多个值 | `MON,WED,FRI` 周一三五 |
| `-` | 范围 | `MON-FRI` 工作日 |
| `/` | 步进 | `0/15` 从 0 开始每 15 一次 |
| `?` | 不指定（仅用于日/周） | 日和周必须有一个是 `?` |
| `L` | 最后（Last） | `L` 在日字段=月末，周字段=周六 |
| `W` | 最近的工作日 | `15W` 离 15 日最近的工作日 |
| `#` | 第几周 | `2#1` 第 1 周的第 2 天（周一） |

#### 13.3.3 在线 Cron 校验

平台在创建定时报告时会自动校验 Cron 表达式格式，错误时给出提示：

- ❌ `格式错误：Cron 表达式必须是 6 或 7 位`
- ❌ `非法字段值：分钟必须在 0-59 之间`
- ❌ `非法组合：日和周不能同时指定，至少一个为 ?`

> 💡 **小贴士**：可以使用 [Cron 表达式在线生成器](https://www.freeformatter.com/cron-expression-generator-quartz.html) 辅助编写，再粘贴到平台中。

### 13.4 启停 / 删除定时报告

#### 13.4.1 启停定时报告

**适用场景**：临时停止报告（如节假日、目标冻结），但保留配置以便后续启用。

**操作步骤**：

1. 进入「定时报告」Tab
2. 在列表中找到目标调度
3. 点击「操作」列的「启停」开关（或「切换状态」按钮）
4. 状态立即生效：
   - **启用**：重新注册到调度器，下次到点正常触发
   - **停用**：立即从调度器移除，下次到点不会触发，配置保留

#### 13.4.2 删除定时报告

**适用场景**：不再需要的调度配置，永久删除。

**操作步骤**：

1. 在列表中找到目标调度
2. 点击「操作」列的「删除」按钮
3. 在确认对话框中输入调度名称二次确认
4. 点击「确认删除」

> ⚠️ **不可恢复**：删除后调度配置永久失效，**但历史执行记录保留 30 天**，仍可在「执行历史」中查看（按 historyId 查询）。

#### 13.4.3 编辑定时报告

定时报告暂不支持直接编辑，如需修改 Cron、收件人、数据源等，请：

1. **停用**原调度
2. **复制**原调度（点击「复制」按钮，自动带入原配置）
3. 修改需要变更的字段
4. **创建**新调度
5. **删除**原调度

定时报告支持自动重试：

- 报告生成失败：自动重试 3 次，间隔 1 分钟
- 邮件发送失败：自动重试 5 次，间隔 2 分钟
- 多次失败后仍失败：标记本次执行为 FAILED，发送飞书告警给创建者

> 💡 **手动触发**：在历史记录页可点击「立即触发」按钮，立即执行一次（不计入 Cron 调度，但会计入历史）。

### 13.6 常见问题

#### Q-T1：邮件未收到怎么办？

A：按以下步骤排查：

1. **查看执行历史**：进入「定时报告」->「历史」，确认该次触发的「邮件状态」
   - **已发送**：检查邮箱垃圾箱、确认收件人地址拼写
   - **发送失败**：查看「错误信息」，常见原因：
     - SMTP 服务不可用（运维侧问题）
     - 收件人邮箱不存在 / 已满
     - 附件过大被拒（PDF 通常 ≤ 25MB）
2. **检查收件人列表**：确认邮箱地址正确，多个邮箱以逗号或换行分隔
3. **联系运维**：若所有定时报告都收不到邮件，可能是 SMTP 服务故障，联系运维排查

#### Q-T2：Cron 表达式不触发？

A：

1. **检查调度状态**：确认调度为「启用」状态（绿色开关）
2. **检查下次触发时间**：在详情页查看「下次触发时间」是否符合预期
3. **检查 Cron 时区**：平台使用 **Asia/Shanghai（UTC+8）** 时区，Cron 表达式按北京时间触发
4. **检查 Cron 语法**：
   - 日和周字段不能同时为 `*`，至少一个为 `?`
   - 月字段不支持 `L`，日字段才支持
5. **检查失效时间**：若已设置 `expireAt` 且当前时间已超过，调度会自动停用
6. **手动触发验证**：在详情页点击「立即触发」按钮验证

#### Q-T3：报告生成失败怎么办？

A：

1. **查看错误信息**：在历史记录中点击失败记录查看「错误信息」
2. **常见原因**：
   - 数据源 ID 不存在（文件/目标/IOC 已删除）
   - 模板不存在或已停用
   - 报告内容过大（PDF 超过 100MB）
3. **处理**：
   - 数据源失效：编辑调度，更新为有效 ID
   - 模板失效：在「报告中心 -> 模板管理」中重新启用或选择新模板
   - 内容过大：在「报告选项」中取消「包含关系图谱」或缩短时间范围

#### Q-T4：可以同时给多少人发邮件？

A：单条调度最多支持 50 个收件人。如需更多，建议：

1. 在邮件侧设置邮件组（如 `apt28-weekly@redteam.example.com`）
2. 在平台中只填邮件组地址
3. 邮件组成员管理在邮件系统侧完成

#### Q-T5：如何查看历史报告内容？

A：在「执行历史」中：

1. 找到目标记录
2. 点击「报告 ID」或「下载」按钮
3. 直接下载 PDF / Word / HTML 文件

历史报告文件保留 30 天，超期后历史记录元数据保留，但报告文件需从对象存储归档恢复。

#### Q-T6：定时报告会消耗配额吗？

A：定时报告生成的报告与手动生成的报告共用同一份配额：

- 单团队空间报告数：默认 10000 份（可扩容）
- 单报告大小：≤ 100MB
- 单报告附件大小：≤ 25MB（邮件附件限制）

#### Q-T7：节假日不发送报告怎么做？

A：V3 迭代已支持节假日自动跳过（详见 13.8 节）：

1. **启用节假日跳过**：编辑定时报告时勾选「跳过节假日」选项（对应 `skipHolidays=true`）
2. **支持范围**：中国法定节假日（元旦、春节、清明、劳动节、端午、中秋、国庆）+ 法定调休日
3. **跳过行为**：节假日 Cron 触发时自动跳过，记录 `SKIPPED` 状态到执行历史，不影响下次执行
4. **节后执行**：节后第一个 Cron 触发时间正常执行，不补跑节假日跳过的报告
5. **配合工作日 Cron**：`0 0 9 ? * MON-FRI` + `skipHolidays=true` 可实现"工作日但跳过调休放假日"效果

> 💡 V3 之前（V2.5）的方案仍可使用：节前手动停用、使用工作日 Cron 排除周末。

#### Q-T8：为什么邮件附件打不开？

A：

1. **PDF 附件**：使用 Adobe Reader / 福昕 / 浏览器内置 PDF 阅读器，避免使用 WPS 旧版
2. **Word 附件**：使用 Office 2016+ 或 WPS 最新版
3. **HTML 附件**：下载后用浏览器打开
4. **大附件下载慢**：建议点击「报告链接」直接在平台内查看，或从「报告中心」列表下载

### 13.7 最佳实践

1. **命名规范**：调度名称采用「对象 + 频率」格式，如 `APT28-周报`、`IOC-日报`、`安全态势-月报`
2. **收件人分组**：使用邮件组而非个人邮箱，便于团队管理
3. **试运行**：创建后先「立即触发」一次，验证报告内容与邮件送达
4. **分级订阅**：周报发给分析员、月报发给主管、季报发给 CTO，避免向上汇报过频
5. **失败告警**：建议在飞书群订阅「定时报告失败」告警，及时发现问题
6. **定期清理**：每季度盘点一次，停用不再使用的调度

### 13.8 节假日跳过（V3 新增）

> V3 迭代新增节假日日历支持，定时报告可在节假日自动跳过执行，避免在非工作日打扰团队。

#### 13.8.1 启用节假日跳过

**操作步骤**：

1. 进入「定时报告」Tab
2. 创建新调度（或复制已有调度后修改）
3. 在「高级选项」中勾选「跳过节假日」开关
4. 保存调度

#### 13.8.2 支持范围

| 范围 | 说明 |
|---|---|
| 法定节假日 | 元旦、春节、清明、劳动节、端午、中秋、国庆 |
| 调休日 | 法定调休放假日跳过；调休上班日正常执行 |
| 日历来源 | 国务院办公厅发布的放假安排，每年初自动更新 |
| 时区 | Asia/Shanghai（UTC+8） |

#### 13.8.3 跳过行为说明

- 节假日 Cron 触发时自动跳过，**不生成报告、不发送邮件/Webhook**
- 跳过记录写入「执行历史」，状态显示为「跳过」（灰色），错误信息标注节假日名称（如 `节假日跳过：2026-02-08 春节`）
- 节后第一个 Cron 触发时间正常执行，**不补跑**节假日跳过的报告
- 节假日跳过不影响 `nextFireTime` 计算与其他调度配置

#### 13.8.4 查看节假日日历

在定时报告详情页可查看当前年份的节假日日历，便于预判跳过时间点。日历包含：
- 日期
- 节假日名称（如「春节」「国庆」）
- 类型：`HOLIDAY`（放假日）/ `WORKDAY`（调休上班日）

> 💡 **使用建议**：节后首日通常报告内容较多（积压多日数据），建议节后第一个工作日 Cron 提前 1 小时触发，或手动触发验证内容。

### 13.9 Slack / 钉钉推送配置（V3 新增）

> V3 迭代在原邮件推送基础上，新增 Slack / 钉钉 Webhook 推送通道，便于实时通知团队。

#### 13.9.1 推送通道选择

在创建/编辑定时报告时，「推送通道」字段（对应 `webhookType`）可选：

| 通道 | 取值 | 说明 |
|---|---|---|
| 仅邮件 | `EMAIL` | 默认，与 V2.5 行为一致，报告作为附件发送 |
| 仅 Slack | `SLACK` | 推送报告摘要 + 下载链接到 Slack 频道 |
| 仅钉钉 | `DINGTALK` | 推送 Markdown 消息（含摘要 + 下载链接）到钉钉群 |
| 全部推送 | `ALL` | 邮件 + Slack + 钉钉同时推送 |

#### 13.9.2 Slack Webhook 配置

**操作步骤**：

1. 在 Slack 工作区创建 Incoming Webhook（参考 Slack 官方文档）
2. 复制 Webhook URL（形如 `https://hooks.slack.com/services/REDACTED`）
3. 在定时报告配置页填写：
   - **Slack Webhook URL**：粘贴 Webhook URL
   - **Slack 频道**：填写频道名（如 `#redteam-intel`），仅用于展示
   - **成功时通知**：开启后报告生成成功推送通知
   - **失败时告警**：开启后报告生成失败推送告警
4. 保存调度

**推送内容**：报告摘要 + 报告名 + 下载链接 + 触发时间。

#### 13.9.3 钉钉 Webhook 配置

**操作步骤**：

1. 在钉钉群创建自定义机器人（参考钉钉官方文档）
2. 选择安全设置（推荐「加签」）
3. 复制 Webhook URL 与加签密钥
4. 在定时报告配置页填写：
   - **钉钉 Webhook URL**：粘贴 Webhook URL
   - **加签密钥**：粘贴以 `SEC` 开头的密钥（启用加签时必填）
   - **成功时通知 / 失败时告警**：同 Slack
5. 保存调度

**推送内容**：Markdown 格式消息，含报告摘要、下载链接、@相关人员。

#### 13.9.4 安全说明

- Slack / 钉钉 Webhook URL 与加签密钥属于敏感信息，平台**加密存储**（SM4 算法）
- API 响应与前端展示均返回**掩码**（如 `https://hooks.slack.com/...REDACTED`），不返回明文
- 仅创建者与管理员可查看完整配置（仍为掩码），其他角色不可见

#### 13.9.5 失败排查

| 现象 | 排查方向 |
|---|---|
| Slack 未收到推送 | 检查 Webhook URL 是否失效、Slack 频道是否归档、网络是否可达 |
| 钉钉未收到推送 | 检查 Webhook URL、加签密钥是否正确、机器人是否被禁用 |
| 推送延迟 | 报告生成与推送为异步，峰值时段可能延迟 1-2 分钟 |
| 全部通道都失败 | 优先查看执行历史错误信息，可能是报告生成失败导致未触发推送 |

## 十四、标签管理与文件打标（V3 新增）

> V3 迭代落地六层标签体系，提供标签字典管理、文件自动/手动打标、按标签检索文件等能力。本章介绍标签相关操作指南。

### 14.1 什么是标签体系

红方平台采用**六层标签体系**对文件进行多维度刻画，标签编码遵循 `层级.分类.名称.值` 规范（如 `L1.FILE.TYPE.EXE` 表示 L1 文件属性层、文件类型组、EXE 类型）。

| 层级 | 名称 | 职责 | 示例 |
|---|---|---|---|
| L1 | 文件属性 | 文件自身客观属性（类型/来源/语言/大小/格式/编码） | PDF、EXE、中文、≥1GB |
| L2 | 业务流程 | 文件在业务链路中的阶段与处理结果 | 上传来源、解析状态、分析结论 |
| L3 | 实体识别 | 从文件内容中提取的结构化实体 | IP（公网/内网/C2）、域名、漏洞、IOC |
| L4 | 业务场景 | 红方 8 大业务场景 | 目标画像、网络地形、凭证获取、漏洞战机 |
| L5 | 情报关联 | 威胁情报与攻击知识库 | APT 组织、TTP、威胁等级、恶意软件家族 |
| L6 | 安全合规 | 数据管控与合规属性 | 密级、保留期、访问限制、脱敏状态 |

**设计原则**：
- **正交性**：同一文件在不同层级可有不同标签，层与层之间不重叠
- **依赖性**：高层级标签依赖低层级标签推导（如 L4 场景标签常由 L3 实体标签推导）
- **可识别性**：L1/L3 以自动识别为主，L2/L4/L5/L6 结合规则推导与人工标注

### 14.2 标签管理操作

**入口**：侧边栏「后台管理」->「标签管理」（V3 新增菜单项）

> ⚠️ **权限要求**：标签字典管理仅 `ADMIN` / `RED_ADMIN` 角色可操作；`ANALYST` 及以下角色仅可查看。

#### 14.2.1 查看标签层级树

1. 进入「标签管理」页面，默认展示 L1-L6 六层标签层级树
2. 操作：
   - 点击层级节点展开/折叠子标签
   - 顶部搜索框输入标签名/编码快速定位
   - 按 `layer` 筛选仅查看指定层级
   - 勾选「仅看启用」隐藏已禁用标签
3. 点击标签节点查看右侧详情面板（编码、识别规则、口径定义、文件数等）

#### 14.2.2 创建标签

1. 点击「新建标签」按钮
2. 填写：
   - **标签编码**：遵循 `层级.分类.名称.值` 规范，全局唯一（如 `L4.SCENE.VULN.EXPLOIT`）
   - **标签中文名**：必须有中文名
   - **层级**：L1-L6
   - **分类**：层内分组（如 `FILE` / `ENTITY` / `SCENE`）
   - **值类型**：ENUM / TEXT / NUMBER / BOOL / DATE
   - **适用对象**：FILE / ENTITY / TARGET / TASK / ALL
   - **识别规则**：自动识别规则描述（可选）
   - **是否多选**：是/否
   - **父标签**：选择父标签编码（可选）
   - **口径定义**：标签含义与边界说明
3. 点击「保存」

> 💡 **编码规范**：标签编码创建后不可修改，请仔细确认格式后再保存。

#### 14.2.3 更新标签

1. 在标签树点击目标标签
2. 点击「编辑」按钮
3. 可更新字段：中文名、识别规则、口径定义、是否多选等
4. **不可更新字段**：标签编码、层级（创建后锁定）
5. 点击「保存」

#### 14.2.4 启用/禁用标签

**适用场景**：某个标签不再使用（如规则误识别率高），但不希望删除已打标的文件标签。

**操作步骤**：

1. 在标签树点击目标标签
2. 点击「启用/禁用」开关（或「切换状态」按钮）
3. 确认操作

**禁用后的影响**：

- 该标签不再出现在自动识别选项中（识别引擎跳过该标签）
- 该标签不再出现在手动打标选项中（用户无法手动打上该标签）
- **已打标文件的标签保留**，但前端展示「已禁用」标识
- 按标签检索文件仍可命中已打标文件

#### 14.2.5 删除标签

**适用场景**：标签创建错误或彻底废弃。

**操作步骤**：

1. 在标签树点击目标标签
2. 点击「删除」按钮
3. 二次确认：
   - 若标签已被文件引用，系统提示「该标签已被 N 个文件引用，是否强制删除？」
   - 选择「强制删除」会级联取消所有文件标签关联
   - 选择「取消」则放弃删除，建议先取消引用再删除
4. 点击「确认删除」

> ⚠️ **不可恢复**：标签删除后不可恢复，已打标文件的该标签关联同步清除。如需保留已打标数据请使用「禁用」而非「删除」。

### 14.3 标签自动识别说明

> 平台在文件解析完成后自动触发标签识别引擎，基于四类规则自动为文件打标。自动标签的 `source` 字段标注识别来源，便于追溯。

#### 14.3.1 四类识别规则

| 规则类型 | source 标识 | 说明 | 示例 |
|---|---|---|---|
| 正则规则 | `AUTO_REGEX` | 基于正则表达式匹配文件内容/元数据 | 文件扩展名 `.exe` → `L1.FILE.TYPE.EXE`；内容含 CVE 编号 → `L3.ENTITY.VULN.CVE` |
| 字典规则 | `AUTO_DICT` | 基于关键词字典匹配 | 文件内容含 APT 组织关键词 → `L5.INTEL.APT.组织名` |
| 模型规则 | `AUTO_ML` | 基于 NER 模型识别实体 | NER 识别到 IP 实体 → `L3.ENTITY.IP`（区分公网/私网） |
| 关联推导 | `AUTO_ASSOC` | 基于已有标签与业务规则推导 | 文件包含目标 IP 且目标画像存在 → `L4.SCENE.TARGET_PROFILE` |

#### 14.3.2 自动识别流程

```
文件上传 → 自动解析 → 解析完成 → 触发标签识别引擎
                                │
                                ▼
                        并行执行四类规则
                                │
                                ▼
                        合并标签结果（去重）
                                │
                                ▼
                        写入 file_tags 表（source=AUTO_*）
                                │
                                ▼
                        前端文件详情页展示「自动标签」区域
```

#### 14.3.3 模型降级策略

当 NER 模型不可用时（如模型加载失败），系统自动降级到正则兜底，不影响主流程：

- 模型状态可通过 `/api/parse/ner/model-status` 查询
- 降级期间识别精度略有下降，但仍能识别基础实体
- 降级事件上报 Prometheus 指标，运维可监控

#### 14.3.4 自动标签 vs 手动标签

| 维度 | 自动标签 | 手动标签 |
|---|---|---|
| 来源标识 | `AUTO_REGEX` / `AUTO_DICT` / `AUTO_ML` / `AUTO_ASSOC` | `MANUAL` |
| 触发时机 | 文件解析完成后自动触发 | 用户在文件详情页手动操作 |
| 操作者 | system | 当前用户 |
| 置信度 | 0-1 浮点数 | 无（视为 1.0） |
| 取消后再打 | 下次识别周期会重新打上 | 需用户手动重新打 |
| 永久屏蔽方式 | 禁用对应标签或识别规则 | 直接取消即可 |
| 修改 | 不可直接修改，需调整识别规则 | 可取消后重新打 |

### 14.4 文件打标操作

#### 14.4.1 查看文件标签

**路径**：文件详情页 -> 「标签」标签页（V3 新增 Tab）

**展示内容**：

| 字段 | 说明 |
|---|---|
| 标签名 | 标签中文名 + 编码 |
| 层级 | L1-L6（颜色标识） |
| 来源 | 自动（正则/字典/模型/关联）/ 手动 |
| 置信度 | 自动标签的识别置信度（0-1） |
| 操作者 | 自动标签为 system，手动标签为操作用户 |
| 操作时间 | 打标时间 |
| 操作 | 取消标签（手动标签可直接取消；自动标签取消后下次识别会重新打） |

#### 14.4.2 手动打标

**路径**：文件详情页 -> 「标签」Tab -> 点击「添加标签」按钮

**操作步骤**：

1. 点击「添加标签」
2. 在弹出的标签选择器中：
   - 按层级/分类筛选候选标签
   - 搜索标签名/编码
   - 多选标签（最多 50 个）
3. 可选填写备注（如「分析师确认 APT28 关联」）
4. 点击「确认打标」

**注意事项**：

- 已禁用的标签不出现在选择器中
- 重复打标自动去重
- 手动标签会与自动标签合并展示，按层级分组

#### 14.4.3 取消标签

## 十五、搜索增强（V3 新增）

> V3 迭代对文件检索能力进行增强，新增布尔组合检索、二次检索、标签筛选、搜索模板、搜索历史等功能，提升高频检索场景效率。

### 15.1 布尔组合检索

> V3 新增 `booleanConditions` 字段，支持 AND/OR/NOT 逻辑组合复杂查询条件，弥补原 `query` 关键词检索的表达力不足。

#### 15.1.1 使用入口

**路径**：文件检索页 -> 「高级筛选」->「布尔组合」展开区（V3 新增）

#### 15.1.2 AND / OR / NOT 使用方法

**条件结构**：每个条件由「字段 + 操作符 + 值」组成，多个条件通过 `AND` / `OR` 组合，支持嵌套（最多 3 层）。

**操作符**：

| 操作符 | 含义 | 示例 |
|---|---|---|
| `CONTAINS` | 包含 | 内容包含"勒索" |
| `NOT_CONTAINS` | 不包含 | 内容不包含"测试" |
| `EQ` | 等于 | 文件类型 = exe |
| `NEQ` | 不等于 | 文件类型 ≠ dll |
| `IN` | 属于 | 文件类型 ∈ [exe, dll, scr] |
| `NOT_IN` | 不属于 | 扩展名 ∉ [log, tmp] |

**可用字段**：`content`（全文）/ `file_name` / `file_type` / `extension` / `tags` 等。

#### 15.1.3 使用示例

**场景 1：检索包含"勒索"但不包含"测试"的 EXE/DLL 文件**

```
AND
├── content CONTAINS "勒索"
├── content NOT_CONTAINS "测试"
└── OR
    ├── file_type IN [exe, dll]
    └── extension EQ "scr"
```

**操作步骤**：

1. 在「布尔组合」区点击「添加条件」
2. 选择字段、操作符、填写值
3. 点击「添加条件组」可创建嵌套逻辑
4. 选择条件组逻辑（AND / OR）
5. 点击「搜索」执行

> 💡 布尔条件与 `query` 关键词取交集，即同时满足关键词与布尔条件的文件才会返回。

### 15.2 二次检索（在结果中搜索）

> V3 新增 `refineQuery` + `refineFileIds` 字段，支持在已有搜索结果范围内进行二次检索，常用于"在结果中搜索"场景。

#### 15.2.1 使用场景

- 首次搜索"勒索病毒"返回 128 条结果
- 想在这些结果中进一步搜索"C2 服务器"
- 使用二次检索，避免全库重新搜索，效率更高

#### 15.2.2 操作步骤

1. 执行首次搜索（如 `query="勒索病毒"`），得到结果列表
2. 在搜索框右侧点击「在结果中搜索」按钮（V3 新增）
3. 输入二次检索关键词（如 `C2 服务器`）
4. 点击「搜索」
5. 结果列表更新为二次检索命中（顶部提示「在 N 条结果中搜索，命中 M 条」）
6. 点击「清除筛选」可回到首次搜索结果

**注意事项**：

- 二次检索不参与向量召回，仅做全文 + 元数据过滤
- 二次检索范围最多 1000 个文件 ID
- 如需语义检索请直接调整 `query` 字段

### 15.3 标签筛选

> V3 新增 `tagIds` 字段，支持按标签筛选文件。配合标签管理体系（详见第十四章），可基于六层标签进行精细化过滤。

#### 15.3.1 操作步骤

1. 在文件检索页点击「高级筛选」
2. 展开「标签」筛选区
3. 按层级浏览标签，勾选一个或多个标签
4. 选择组合逻辑：
   - **同时包含（AND）**：默认，文件需同时具有所有选中标签
   - **任一包含（OR）**：文件具有任一选中标签即可
5. 搜索结果实时更新
6. 搜索结果中每条文件展示命中的标签列表

#### 15.3.2 典型场景

| 场景 | 标签组合 | 逻辑 |
|---|---|---|
| 查找所有 APT28 相关样本 | `L5.INTEL.APT.APT28` | 单标签 |
| 查找包含公网 IP 的可执行文件 | `L1.FILE.TYPE.EXE` + `L3.ENTITY.IP.PUBLIC` | AND |
| 查找涉密或敏感文件 | `L6.COMP.CLASSIFICATION.SECRET` + `L6.COMP.ACCESS.RESTRICTED` | OR |
| 查找漏洞利用场景的非测试文件 | `L4.SCENE.VULN.EXPLOIT` + 非 `L2.FILE.TAGS.TEST` | AND + NOT |

> 💡 标签筛选可与布尔组合、二次检索叠加使用，实现复杂查询。

### 15.4 搜索模板

> V3 新增搜索模板能力，可将常用搜索条件保存为模板，后续一键应用，避免重复配置。

#### 15.4.1 保存搜索模板

**操作步骤**：

1. 在文件检索页配置好搜索条件（关键词、模式、布尔条件、标签、过滤器等）
2. 点击搜索框右侧的「保存搜索」按钮（V3 新增）
3. 填写：
   - **模板名称**：便于识别（如「APT28 周报检索」），最长 64 字符
   - **模板描述**：可选，最长 256 字符
   - **是否公开**：开启后团队空间成员可见，关闭则仅创建者可见
4. 点击「保存」

**保存内容**：完整的搜索请求体（query / modes / filters / booleanConditions / tagIds / tagLogic 等）。

#### 15.4.2 应用搜索模板

**操作步骤**：

1. 在文件检索页点击「搜索模板」下拉（V3 新增，位于搜索框下方）
2. 浏览模板列表（按最近使用排序）
3. 点击目标模板
4. 搜索条件自动填充并立即执行搜索
5. 可在已填充条件基础上继续修改后再次搜索

#### 15.4.3 删除搜索模板

1. 点击「搜索模板」下拉右侧的「管理」按钮
2. 在模板管理弹窗中找到目标模板
3. 点击「删除」按钮
4. 二次确认

**权限说明**：

- 仅创建者与管理员可删除模板
- 公开模板删除后，其他用户的引用同步失效
- 单用户最多保存 50 个模板

#### 15.4.4 典型场景

| 场景 | 模板内容 |
|---|---|
| APT28 周报检索 | query=APT28 + extension=[exe,dll] + tag=APT28 |
| 涉密文件审计 | tagIds=[L6.COMP.CLASSIFICATION.SECRET] + tagLogic=AND |
| 高威胁样本筛查 | filters.risk_level=[HIGH,CRITICAL] + modes=[FULLTEXT,VECTOR] |
| 钓鱼邮件分析 | query="钓鱼邮件" + extension=[eml,msg] + booleanConditions |

### 15.5 搜索历史

> V3 新增搜索历史记录，每个用户最近 20 条搜索自动保存到浏览器 localStorage，便于快速重新执行。

#### 15.5.1 查看搜索历史

**路径**：文件检索页 -> 「历史」标签页

**展示内容**：

| 字段 | 说明 |
|---|---|
| 搜索条件摘要 | 关键词 + 模式 + 过滤条件 |
| 命中数 | 当时搜索的结果数 |
| 搜索时间 | YYYY-MM-DD HH:mm |
| 操作 | 重新执行 / 删除 |

#### 15.5.2 从历史恢复搜索

1. 在「历史」标签页找到目标记录
2. 点击「重新执行」按钮
3. 搜索条件自动恢复并重新执行搜索
4. 结果列表更新为最新命中（可能与历史命中数不同，因为数据已变化）

#### 15.5.3 清空搜索历史

**全部清空**：

> ⚠️ **存储位置**：搜索历史保存在浏览器 localStorage，**不跨设备/浏览器同步**。清理浏览器缓存会丢失历史记录。如需跨设备使用，请保存为「搜索模板」（存储在服务端）。

## 十六、常见问题

### 16.1 登录问题

#### Q1：忘记密码怎么办？

A：在登录页点击「忘记密码」，输入注册邮箱，通过邮件重置密码。如未收到邮件，请联系管理员。

#### Q2：MFA 验证码不正确？

A：
1. 检查手机时间是否准确（TOTP 依赖时间）
2. 确认 TOTP 应用中的账号是当前平台账号
3. 使用备用码登录
4. 联系管理员重置 MFA

#### Q3：登录后提示「账号已禁用」？

A：账号被管理员禁用，请联系管理员启用。

### 16.2 文件上传问题

#### Q4：上传失败提示「文件大小超过限制」？

A：
- 单文件最大 5GB
- 联系管理员调整团队空间配额

#### Q5：上传失败提示「文件类型不支持」？

A：文件类型不在白名单。联系管理员添加支持的类型。

#### Q6：分片上传中断后能否续传？

A：可以。重新选择同一文件上传，系统自动从断点续传。

#### Q7：秒传命中是什么意思？

A：平台已存在相同哈希的文件，无需重复上传，直接关联到已有文件。

### 16.3 检索问题

#### Q8：搜索结果为空？

A：
1. 检查关键词拼写
2. 尝试简化关键词
3. 切换检索模式（启用语义检索）
4. 检查团队空间筛选

#### Q9：语义检索找不到相似文件？

A：语义检索需要文件已解析并生成向量索引。请等待文件解析完成。

#### Q10：搜索响应慢？

A：
1. 缩小时间范围
2. 减少返回条数
3. 使用元数据过滤
4. 联系管理员检查 ES 性能

### 16.4 分析问题

#### Q11：分析任务一直排队？

A：分析任务有并发限制。请稍候，或联系管理员调整优先级。

#### Q12：沙箱分析失败？

A：
1. 文件类型不支持沙箱执行
2. 沙箱资源不足
3. 文件触发沙箱保护机制
4. 联系管理员查看沙箱日志

#### Q13：IOC 提取结果为空？

A：文件中可能确实不包含 IOC。可尝试：
1. 检查文件是否已解析
2. 手动触发分析
3. 自定义 IOC 规则

### 16.5 定时报告问题

> 定时报告常见问题已整合到第十三章 13.6 节（Q-T1 ~ Q-T8），此处不再重复。
