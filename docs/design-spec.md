## 1. 设计原则

### 1.1 视觉风格定位

本平台面向网络安全红方专业人员，视觉风格需体现**专业、高效、安全、技术**四大核心特征。

#### 1.1.1 专业性

- 采用**深色主题为默认主题**（浅色主题为可选切换），营造专业、严肃的工作氛围
- 界面布局清晰有序，信息层次分明
- 避免过度装饰，保持界面简洁专业
- 数据展示精确、直观，便于专业人员快速获取信息

#### 1.1.2 高效性

- 优化操作流程，减少用户点击次数
- 重要操作入口明显，次要功能合理收纳
- 支持快捷键操作，提升专业用户效率
- 表格、列表支持批量操作，提高工作效率

#### 1.1.3 安全性

- 采用稳重的色彩体系，传递安全可信赖的感觉
- 敏感操作需二次确认，防止误操作（详见 [8.7 危险操作分级](#87-危险操作分级)）
- 权限状态清晰可见，用户始终了解自己的权限范围
- 安全提示醒目但不突兀，不打断用户工作流
- **密级标识体系**贯穿所有文件、报告、目标画像（详见 [2.7 密级标识色](#27-密级标识色)）

#### 1.1.4 技术感

- 采用科技感的配色方案（深空蓝 #0B3D91、赛博青 #00D9FF、霓虹绿 #39D353）
- 数据可视化采用专业图表风格
- 代码、日志、哈希值等内容使用等宽字体展示
- 界面元素带有适度的技术感细节（边框、阴影、渐变）
- 深色模式参考标杆：VS Code Dark+、GitHub Dark、Burp Suite

### 1.2 用户体验原则

#### 1.2.1 一致性原则

| 维度 | 说明 |
|-----|------|
| 视觉一致 | 相同功能的组件保持视觉样式一致 |
| 交互一致 | 相同操作行为保持交互方式一致 |
| 文案一致 | 相同概念使用统一术语 |
| 布局一致 | 相同类型页面保持布局结构一致 |
| 数值一致 | 三份文档（design-spec / prototype / interaction-flow）共享同一套数值（详见 [附录C](#附录c数值统一对照表)） |

#### 1.2.2 反馈原则

| 场景 | 反馈方式 |
|-----|---------|
| 操作成功 | 轻量级成功提示，自动消失（3秒） |
| 操作失败 | 明确的错误信息，提供解决方案（5秒） |
| 加载中 | 加载动画或进度条 |
| 操作确认 | 二次确认弹窗（按危险等级分级） |
| 状态变化 | 实时更新状态显示 |
| 可撤销操作 | Gmail式撤销Toast，5秒倒计时（详见 [8.6 撤销机制](#86-撤销机制)） |

#### 1.2.3 容错原则

- 危险操作（删除、清空等）需二次确认，按 [8.7 危险操作分级](#87-危险操作分级) 执行
- 提供撤销功能，支持操作回退（5秒有效期）
- 表单输入提供实时校验和友好提示
- 错误信息清晰明确，指导用户解决问题

#### 1.2.4 效率原则

- 支持键盘快捷键操作（30+快捷键，详见 [8.5 快捷键规范](#85-快捷键规范)）
- 常用功能支持收藏和快捷访问
- 搜索支持历史记录和智能建议
- 列表支持多选和批量操作

#### 1.2.5 可访问性原则

- 色彩对比度符合 WCAG 2.1 AA 标准（正文 ≥4.5:1，大字 ≥3:1）
- 所有交互元素支持键盘访问
- 图片提供替代文本
- 表单元素关联标签
- 完整ARIA规范见 [9. 可访问性规范](#9-可访问性规范)

## 2. 色彩体系

### 2.1 主题策略（深色为默认）

> **P0修复#3**：明确深色主题为默认主题，浅色主题为可选切换。所有色彩值必须提供深色模式和浅色模式两套色值。

| 主题 | 状态 | 默认 | 切换入口 |
|-----|------|------|---------|
| 深色主题（Dark） | 默认 | ✓ | 顶部导航 → 主题切换 / `Ctrl + ,` |
| 浅色主题（Light） | 可选 | - | 同上 |
| 跟随系统（Auto） | 可选 | - | 同上 |

**实现策略：**
- 通过 `data-theme="dark|light"` 属性挂在 `<html>` 根节点
- 所有色彩通过 CSS 自定义属性（CSS Variables）切换
- 用户主题偏好持久化到 localStorage，键名 `rt-theme`
- 首次访问默认深色主题

### 2.2 Design Token 三层体系

> **P1修复**：建立全局令牌→语义令牌→组件令牌的三层体系。

#### 2.2.1 全局令牌（Global Tokens）

原始色板，不直接用于组件，作为设计系统的"色卡"。

```css
:root {
  /* 品牌色板 */
  --color-brand-deep:   #0B3D91;  /* 深空蓝（品牌Logo色） */
  --color-brand-blue:   #0052CC;  /* 品牌蓝（浅色模式主色） */
  --color-brand-cyan:   #00D9FF;  /* 赛博青（强调色） */
  --color-brand-green:  #39D353;  /* 霓虹绿 */
  --color-brand-purple: #A371F7;  /* 科技紫 */

  /* 中性色板 - 深色 */
  --color-dark-0: #0D1117;
  --color-dark-1: #161B22;
  --color-dark-2: #21262D;
  --color-dark-3: #30363D;

  /* 中性色板 - 浅色 */
  --color-light-0: #FFFFFF;
  --color-light-1: #F5F7FA;
  --color-light-2: #EBEDF0;
  --color-light-3: #D9D9D9;

  /* 功能色板 */
  --color-success: #52C41A;
  --color-warning: #FAAD14;
  --color-error:   #FF4D4F;
  --color-info:    #1890FF;

  /* 功能色文字（WCAG达标） */
  --color-success-text: #237804;
  --color-warning-text: #AD6800;
  --color-error-text:   #A8071A;
  --color-info-text:    #0052CC;
}
```

#### 2.2.2 语义令牌（Semantic Tokens）

按用途命名的色值，绑定到具体语义，随主题切换。

```css
[data-theme="dark"] {
  --color-bg-primary:    var(--color-dark-0);   /* 页面主背景 */
  --color-bg-secondary:  var(--color-dark-1);   /* 卡片背景 */
  --color-bg-tertiary:   var(--color-dark-2);   /* 输入框背景 */
  --color-bg-elevated:   var(--color-dark-2);   /* 浮层背景 */
  --color-border-base:   var(--color-dark-3);   /* 默认边框 */
  --color-border-split:  var(--color-dark-3);   /* 分割线 */
  --color-text-primary:   #C9D1D9;              /* 正文 11.5:1 */
  --color-text-secondary: #8B949E;              /* 次要 4.6:1 */
  --color-text-disabled:  #484F58;
  --color-text-placeholder: #6E7681;
  --color-link:           #58A6FF;
  --color-link-hover:     #79B8FF;
  --color-brand:          #1F6FEB;              /* 深色模式品牌主色 */
  --color-brand-hover:    #388bfd;
  --color-brand-active:   #1158c7;
  --color-accent:         var(--color-brand-cyan);
}

[data-theme="light"] {
  --color-bg-primary:    var(--color-light-0);
  --color-bg-secondary:  var(--color-light-1);
  --color-bg-tertiary:   var(--color-light-2);
  --color-bg-elevated:   var(--color-light-0);
  --color-border-base:   var(--color-light-3);
  --color-border-split:  #E8E8E8;
  --color-text-primary:   #1F2329;
  --color-text-secondary: #646A73;
  --color-text-disabled:  #BBBFC4;
  --color-text-placeholder: #8F959E;
  --color-link:           var(--color-info-text);
  --color-link-hover:     #40A9FF;
  --color-brand:          var(--color-brand-blue);
  --color-brand-hover:    #40A9FF;
  --color-brand-active:   #096DD9;
  --color-accent:         #00B4D8;
}
```

#### 2.2.3 组件令牌（Component Tokens）

绑定到具体组件的色值，从语义令牌派生。

```css
.btn-primary {
  --btn-bg: var(--color-brand);
  --btn-bg-hover: var(--color-brand-hover);
  --btn-bg-active: var(--color-brand-active);
  --btn-text: #FFFFFF;
  --btn-border: var(--color-brand);
}
```

### 2.8 色彩对比度规范

为确保可访问性，文字与背景的色彩对比度需符合以下标准：

| 场景 | 最小对比度 | 推荐对比度 | 标准 |
|-----|-----------|-----------|------|
| 正文文字 | 4.5:1 | 7:1 | WCAG AA / AAA |
| 大标题（18px以上） | 3:1 | 4.5:1 | WCAG AA / AAA |

#### 3.1.4 字体加载策略

> **P1修复**：补充字体加载策略。

```css
/* font-display: swap 保证文字先以系统字体显示，自定义字体加载后替换 */
@font-face {
  font-family: "Source Han Sans SC";
  src: url("https://cdn.example.com/fonts/source-han-sans-sc-subset.woff2") format("woff2");
  font-weight: 400 700;
  font-display: swap;
  unicode-range: U+4E00-9FFF, U+3000-303F, U+FF00-FFEF; /* 中文字集子集化 */
}

@font-face {
  font-family: "JetBrains Mono";
  src: url("https://cdn.example.com/fonts/jetbrains-mono-subset.woff2") format("woff2");
  font-weight: 400 700;
  font-display: swap;
  unicode-range: U+0000-007F, U+0080-00FF; /* ASCII + Latin-1 */
}
```

**加载策略：**
- 使用 `font-display: swap` 避免FOIT（Flash of Invisible Text）
- 中文字体进行子集化，仅包含常用3500汉字 + ASCII
- 通过 CDN 加速分发，使用 woff2 格式（体积压缩 30%）
- 预连接（preconnect）字体CDN域名
- 仅加载使用到的字重（400 / 500 / 600 / 700）

#### 8.5.3 快捷键冲突检测

**冲突检测规则：**
1. 同一上下文（页面/组件）内不允许重复快捷键
2. 浏览器保留快捷键（Ctrl+N/T/W/L 等）禁止覆盖
3. 输入框聚焦时，单字符快捷键（如 ?）失效
4. 当用户自定义快捷键与系统冲突时，弹出提示让用户选择

**冲突检测实现：**
```ts
function checkShortcutConflict(newShortcut: Shortcut): ConflictResult {
  // 1. 检查浏览器保留键
  if (BROWSER_RESERVED.has(newShortcut.key)) return { type: 'browser' };
  // 2. 检查同上下文冲突
  const sameContext = registry.get(newShortcut.context) ?? [];
  if (sameContext.some(s => s.matches(newShortcut))) return { type: 'context' };
  // 3. 检查全局冲突
  if (newShortcut.isGlobal && globalRegistry.has(newShortcut.key)) {
    return { type: 'global', conflict: globalRegistry.get(newShortcut.key) };
  }
  return { type: 'none' };
}
```

**全局快捷键统计：** 共 21 个全局快捷键 + 7 个列表快捷键 + 业务页面快捷键 = 总计 30+ 快捷键。

### 9.2 焦点管理

#### 9.2.1 焦点陷阱（Focus Trap）

> 弹窗、抽屉打开时，焦点必须被困在弹窗内，Tab 循环不会跳到弹窗外元素。

```ts
function trapFocus(container: HTMLElement) {
  const focusable = container.querySelectorAll(
    'button, [href], input, select, textarea, [tabindex]:not([tabindex="-1"])'
  );
  const first = focusable[0] as HTMLElement;
  const last = focusable[focusable.length - 1] as HTMLElement;

  // 打开时聚焦第一个元素
  first.focus();

  container.addEventListener('keydown', (e) => {
    if (e.key !== 'Tab') return;
    if (e.shiftKey) {
      if (document.activeElement === first) {
        e.preventDefault();
        last.focus();
      }
    } else {
      if (document.activeElement === last) {
        e.preventDefault();
        first.focus();
      }
    }
  });
}
```

#### 9.2.2 焦点恢复

弹窗关闭后，焦点必须返回到触发弹窗的元素：

```ts
const trigger = document.activeElement;
openModal();
// ... 弹窗关闭后
trigger.focus();
```

#### 9.2.3 :focus-visible 样式规范

```css
/* 仅在键盘聚焦时显示焦点环 */
:focus-visible {
  outline: 2px solid var(--color-brand);
  outline-offset: 2px;
  border-radius: 4px;
}

/* 鼠标点击不显示焦点环 */
:focus:not(:focus-visible) {
  outline: none;
}

/* 暗色模式焦点环 */
[data-theme="dark"] :focus-visible {
  outline-color: #58A6FF;
}
```

**焦点环规范：**
- 颜色：#0052CC（浅）/ #58A6FF（深）
- 粗细：2px
- 偏移：2px
- 形状：跟随元素圆角
